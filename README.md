# 🧪 ChemistryQuiz

A **Python Tkinter Chemistry Quiz** application with multiple-choice questions, interactive GUI, and score tracking.  
Test your chemistry knowledge with **10 shuffled questions**, navigate between previous and next questions, and track your score.

## 🚀 Features
- 10 multiple-choice chemistry questions
- Questions and options are shuffled every time
- Score tracking for correct answers
- Navigate between previous and next questions
- Enter your name to personalize your quiz experience
- Friendly graphical interface using Tkinter
