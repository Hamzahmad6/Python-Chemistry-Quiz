# 🧪 Advanced Chemistry Exam System

A **full-featured Python Tkinter-based examination system** that simulates a real online exam environment.  
It includes **student login, timed quiz, navigation system, auto-scoring, and result storage in a file**.

## 🚀 Features

- 🧑 Student login system (Name, Age, ID validation)
- ⏱ Countdown timer (auto-submits when time ends)
- ❓ 15 shuffled chemistry multiple-choice questions
- 🔁 Navigation (Previous / Next question)
- 💾 Saves student results automatically to `results.txt`
- 📊 Automatic scoring system
- 🎯 Grade system (Excellent / Very Good / Good / Fail)
- 🎨 Modern dark-themed GUI using Tkinter
- 🔄 Restart or exit after exam completion

---

## 🧪 How It Works

1. Enter your **name, age, and student ID**
2. Click **Start Exam**
3. Answer questions using multiple choice buttons
4. Use **Next / Previous** to navigate
5. Timer counts down from **5 minutes**
6. Exam ends automatically or manually
7. View your:
   - Score
   - Percentage
   - Grade
8. Results are saved in `results.txt`
